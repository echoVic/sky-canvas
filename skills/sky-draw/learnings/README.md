# learnings — 画布领域经验

这里沉淀"画某类图的惯用 ops 序列",独立于 SDK 代码生长。agent 在动手前扫一眼,能少走弯路。

每个 `.md` 是一类图的 playbook:什么结构、常用坐标节奏、常踩的坑。

## 已有经验

- [bar-chart.md](bar-chart.md) — 柱状图:坐标轴 + 等距柱子 + 标签
- [flow-diagram.md](flow-diagram.md) — 流程图/节点图:节点 + connect 连线 + 分组移动

## 怎么加一条经验

跑通一类图后,把"可复用的 ops 序列骨架 + 关键数值节奏 + 遇到的坑"记成一个 `.md`,在上面挂一行索引。经验的价值在于**下次不用重新试错**。
